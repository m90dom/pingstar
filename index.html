Twilio missed-call recovery

Existing local or mobile number → unanswered divert → Twilio → SMS → AI booking.

Checking…
Office number→No answer / busy→Twilio→SMS booking link
  1. Buy an SMS-capable Twilio number or configure a Messaging Service.
  2. Ask the existing phone carrier to enable conditional call forwarding on no-answer/busy to the Twilio number.
  3. Set the Twilio number Voice webhook to /api/webhooks/twilio/incoming-call.
  4. Use TWILIO_CALL_MODE=recovery-only when the existing number rings first.
  5. Test from an external phone and confirm the SMS opens the customer chatbot.

Production checklist

  • User authentication and role-based access
  • Encryption in transit and at rest
  • Consent, retention and deletion controls
  • Audit logging for every record access
  • Clinical-system and calendar integrations
  • Human approval before sensitive actions

About the AI chatbot

The chatbot first tries the secure /api/chat server endpoint. When no API key or server is available, it automatically falls back to the original local rule-based demo. The API key is never stored in the browser.
